# Contributing

Issues and pull requests are welcome.

1. Fork the repository and create a focused branch.
2. Keep hardware-specific protocol changes isolated and documented.
3. Run `node --check main.js`, `node --check ui/app.js`, and `python -m py_compile engine.py`.
4. Test changes on real hardware before submitting a pull request.

Never commit vendor SDK binaries, build output, credentials, device identifiers, or personal paths.
